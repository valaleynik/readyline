# Brand

Source of truth: the Readyline design system artifact (https://claude.ai/artifact/RPEzRscmyoYF1TGR69tNax). These are copies for the code:
logo SVGs: the wordmark (Inter ExtraBold outlined, y tail as the pass line with a slate-to-copper gradient, copper square on the i; built by final.py, which chains wordmarks*.py) and the mark (make-logo.py), tokens.json, and components.css (the `rl-` component classes).
Palette "Slate and Copper": #1E293B slate, #D97706 copper (action only), #F8FAFC alabaster, #0EA5E9 sky (on track), #B45309 amber (behind). Never white text on copper.
